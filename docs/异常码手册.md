# 异常码手册

技术严重度 `warning/error` 用于运行状态；业务等级 `L1-L4` 用于决定是否允许自动处理，两者不得混用。

| 异常码 | 业务等级 | 技术严重度 | 含义 | 默认动作 | 权威来源 |
| --- | --- | --- | --- | --- | --- |
| `OT_NEGATIVE_HOURS` | L3 | error | 加班工时为负 | 提醒并隔离，禁止自动修正 | ERP；身份字段以 HR 为准 |
| `OT_ZERO_HOURS` | L2 | warning | 加班工时为零，记录仍输出 | 按审批状态和企业规则决定；当前保留并警告 | ERP / OA |
| `IDENTITY_NAME_CONFLICT` | L3 | error | 同一工号对应多个姓名 | 隔离该工号全部记录，禁止自动处理 | HR Master Data |
| `ROW_INVALID` | L3 | error | 必填值、日期、时间或数值非法 | 保留原值并隔离；不得猜测实际值 | 按字段归属 |
| `LEAVE_DOCUMENT_DUPLICATE` | L3 | error | 请假单号为空或重复 | 暂停相关记录，确认有效单据 | OA |
| `BALANCE_MISSING` | L3 | error | 找不到对应年假余额 | 暂停请假单并补充余额记录 | HR Master Data |
| `BALANCE_DUPLICATE` | L3 | error | 同一工号存在多条余额 | 暂停并确认唯一有效余额 | HR Master Data |
| `BALANCE_IDENTITY_CONFLICT` | L3 | error | 姓名或部门不一致 | 暂停并按有效期核对主数据 | HR Master Data |
| `BALANCE_INVALID` | L3 | error | 年假余额非法 | 保留原值并隔离，不自行归零 | HR Master Data |

L4 不应直接产生自动处置结果。新字段、新模板或新业务规则进入“建议 → 人工确认 → 权限校验 → 新规则版本 → 发布”的流程。
